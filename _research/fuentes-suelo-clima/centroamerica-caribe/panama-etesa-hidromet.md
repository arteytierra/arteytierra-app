# Panamá — datos históricos hidrometeorológicos (ETESA)

**Tipo:** clima | precipitación | evaporación
**Estado:** DESCARTADA
**Prioridad sugerida:** baja

## Qué mejora sobre la fuente global

La red nacional contiene observaciones meteorológicas/hidrológicas locales que podrían mejorar NASA POWER.

## Cobertura

Panamá, por estaciones de la red de Hidrometeorología.

## Licencia

No se encontró licencia abierta comercial. La documentación de transparencia registra “Venta de Datos Meteorológicos”, indicando provisión arancelada y no datos abiertos reutilizables.

## Acceso técnico

No se encontró API pública histórica por punto/bbox. La información se tramita/descarga mediante el portal institucional.

## Campos que devuelve

Según solicitud/producto: precipitación, temperatura y otras variables de estación.

## Qué falta o qué no da

Endpoint, licencia comercial de redistribución, precios/contrato aptos para producto y respuesta automática.

Revisado el 2026-08-31. El informe oficial de transparencia disponible en `https://www.etesa.com.pa/documentos/INFORME_DE_TRANSPARENCIA_junio__2022.pdf` contiene el concepto `Venta de Datos Meteorológicos`; no apareció un servicio de consulta vivo que produzca registros por coordenada.
